A browser-based serial telemetry tool for reading and writing data to microcontrollers — no drivers or installs required, just the Web Serial API with vanilla JavaScript and CSS. It is used by SJSU Robotics and in San Jose State University's embedded systems courses, and is open source on [GitHub](https://github.com/libhal/web-serial).
