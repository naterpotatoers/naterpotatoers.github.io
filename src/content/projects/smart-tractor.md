An autonomous rover that patrols GPS waypoints and samples soil moisture, temperature, humidity, and air quality along the way. The robot pulls its patrol route as JSON from a web server, navigates with an onboard GPS module, uses computer vision to spot birds threatening crops, and uploads its readings to AWS for visualization on a React dashboard built around Google Maps.

Won **Best Use of Web Automation Technology** at MakeUC 2022.
