A wildfire monitoring system built on a distributed LoRaWAN sensor network. Solar-powered nodes deployed in the field capture temperature, humidity, and smoke readings and relay them long-range to a leader node, which pushes everything to an Azure-hosted Express/MySQL backend. A React dashboard visualizes sensor status in real time.

Won **1st Place Overall** and **Best Use of Azure** at SCEHacks 2021.
