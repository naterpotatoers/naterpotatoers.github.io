An IoT barbell collar that automatically counts reps and time under tension. A Raspberry Pi Pico W reads an MPU6050 IMU to detect lifts, with a custom three-button OLED interface for selecting exercises and weight. Workouts sync to a TypeScript/React/Node/MySQL app on AWS (EC2, RDS, S3), deployed via GitHub Actions, where users track progress and compete on exercise leaderboards.

Won **Best Health Hack** at CruzHacks 2023.
